# TASK-0026: Integrate customizable dashboard endpoint in dukaDesk frontend

## Parent Feature

- [FEAT-0008 Customizable Merchant Dashboard](../features/FEAT-0008.md)

## Engineering Specification

- [UI-0004 Tenant Dashboard Foundation and Shell](../../engineering-specifications/specifications/ui/UI-0004.md)

## Repository Target

- dukaDesk/

## Description

Consume the new backend endpoint `GET /api/v1/merchants/:id/dashboard` in `dukaDesk/src/components/pages/Dashboard.jsx` and `src/runtime/VerticalContext.jsx`. Replace the current static `verticalPresetModules` + local `getDashboardModules()` logic with a SWR/fetch that is gated by integrations.

## Acceptance Criteria

- [ ] `VerticalContext` fetches `GET /api/v1/merchants/:id/dashboard` on mount (with fallback to `verticalPresetModules` when offline/demo).
- [ ] `Dashboard.jsx` renders `kpis`/`quickActions`/`widgets` from the endpoint response, not just local `vertical.kpis`.
- [ ] When `Integrations.jsx` toggles an integration, `VerticalContext` invalidates and refetches dashboard config.
- [ ] E2E: enable/disable `Paystack` integration → dashboard KPI appears/disappears without reload.
