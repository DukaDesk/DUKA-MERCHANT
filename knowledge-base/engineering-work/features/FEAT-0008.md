# FEAT-0008: Customizable Merchant Dashboard (Integration-Aware)

## Identifier

FEAT-0008

## Description

Make the merchant dashboard in `dukaDesk` fully customizable based on what is integrated for the merchant. The dashboard must not be static; its KPIs, quick actions, widgets, and sidebar modules must be gated by the merchant's enabled integrations, vertical, and subscription plan. An explicit backend endpoint must be the source of truth for "what is integrated" and for the resolved dashboard layout.

Currently `dukaDesk/src/components/pages/Dashboard.jsx:102` renders from `VerticalContext` (`vertical.kpis`, `vertical.quickActions`) and local `PRIMITIVE_BY_ID`/`enabledIds` from `getDashboardModules()`. It does not call a backend endpoint that considers `GET /api/v1/bff/tenant/:id/integrations` or the merchant's integration state. This leads to showing modules that are not installed, or hiding modules that should be visible.

## Acceptance Criteria

- [ ] Backend exposes `GET /api/v1/merchants/:id/dashboard` (or `GET /api/v1/bff/tenant/:id/dashboard`) that returns `{ kpis: [], quickActions: [], widgets: [], enabledModules: [], layout: {} }` resolved from `merchant.integrations`, `merchant.vertical`, and `merchant.subscription`.
- [ ] Endpoint considers `GET /api/v1/bff/tenant/:id/integrations` and `GET /api/v1/merchants/:id/features` as source of truth; does not trust client `enabledIds` alone.
- [ ] `dukaDesk` `Dashboard.jsx` and `VerticalContext.jsx` call the new endpoint on load (with SWR/caching), gated by `useVertical` and `PRIMITIVE_BY_ID`, and render only modules where `moduleGate` passes AND backend says `integrations` includes the required primitive.
- [ ] When an integration is toggled via `Integrations.jsx` (`POST /merchants/:id/integrations/connect`), the dashboard invalidates and refetches the layout.
- [ ] Fallback to local `verticalPresetModules` when backend unavailable (demo mode), but source of truth remains backend when available.
- [ ] E2E test: enable `Paystack` → `kpi_revenue` appears; disable → disappears.
